How does pairing work?
  1. One device taps Share and gets a code (or QR).
  2. The other taps Receive, pastes the code (or scans the QR), and gets a reply code.
  3. The sharer pastes the reply code and taps Connect. Done — send anything.

Your photos and files fly directly between the devices (WebRTC) — no server ever sees them, and codes are single-use. Same Wi-Fi works best.

Once connected, chat and files are end-to-end encrypted between your devices (AES-GCM, with a safety code you can compare) when both run v21.3 — older versions use WebRTC's built-in transport encryption. Nothing is stored: keys and chats vanish when you disconnect. Big files (64 MB+) stream straight to device storage instead of filling memory, so multi-GB transfers don't blow up your phone's RAM.

⚙️ Connection settings

A TURN relay is only used when a direct connection can't get through (some mobile and office networks). A free public relay is already built in as a fallback; your own is used in addition. Stored only on this device.
